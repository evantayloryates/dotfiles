## Supported agent workflow

1. Read the intended consumer's `status`, inspect the exact target and use
   `production_plan`. Reuse existing app observations only within their recorded
   environment. A plan is not proof that the target is visible in the source.
2. Choose a qualified source. Use a window for contained content; prefer a
   qualified fixed app crop or padded display when menus can overflow. Verify
   actual menu pixels, not only canvas containment. Chrome native-select,
   TextEdit, Safari and Electron lanes have distinct recorded limits; consult
   their existing runbooks. Safari's retained black-tail failure remains relevant.
3. Explain focus/occlusion risks for this arrangement. Background capture,
   cooperative actions and reserved production time remain distinct. Keep user
   input available; interruptions are permitted. A notification click starts
   the agreed interval; prepare before requesting it and reserve cleanup time.
   Admission checks are snapshots, not hard cancellation or an input lock.
4. Capture with the intended cursor/helper settings and input policy. Broad
   delivered shortcuts and contextual candidates can be retained. Record
   semantic action blocks; unrelated same-app input may remain ambiguous.
   A browser action can succeed while global telemetry is empty. Inspect
   listener/gap/protected-input evidence; do not synthesize missing events.
5. Inspect terminal state, source journal and representative previews around
   transitions. Use returned rational decoder time and source mapping, not the
   requested preview offset. Fitted isolated-window coordinates can be refused
   even when the video is useful; use the qualified source instead of guessing.
6. Preserve and label disturbed intervals. Depending on available pixels, trim,
   use a separately verified backup, or reshoot. Independent streams can show
   different animated states despite close timestamps. Automatic frame-perfect
   animated repair is unavailable. Do not replay an uncertain mutation; recover
   its session/recording/action/export identity first.
7. Use draft previews/exports for inspection, then select standard/full effort
   when needed. Export names are immutable; exact parent/export time mapping is
   service-owned. Close the owned session with `session_update state:closed`
   (CLI `close`), then read back `session_show state:closed`. A filename or an
   update reply is not closure evidence. Keep receipt, verification and cleanup
   outcomes separate. Do not reacquire a closed native app to check its absence.

## Disposition of remaining broad qualification items

The remaining items retain their original scopes/statuses. None requires a new
feature to use the workflow above under these stated limits.
