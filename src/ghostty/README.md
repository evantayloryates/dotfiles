# Ghostty config

`~/.config/ghostty` links to this directory. The former config lived at
`~/.config/kitty/ghostty/config`; the terminal is Ghostty, so its source now
lives independently of the retired Kitty configuration.

Run `./install.sh` here to check or install the link. The installer refuses to
replace another directory or a link to a different source. Validate changes
with `/Applications/Ghostty.app/Contents/MacOS/ghostty +validate-config`.
